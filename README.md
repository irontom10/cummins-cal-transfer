# Cummins CAL Transfer

Windows x86 tool for downloading and uploading Cummins ECM calibration data over **CLIP / J1939 / RP1210**.

The project is split into a C89 native core and a .NET 10 WinForms front end. The native RP1210/CLIP DLL is embedded into the final executable and extracted to a versioned per-user cache at runtime.

## What it does

- **Download CAL** from an ECM and write a Calterm-style `.ccal`.
- **Upload CCAL** after validating the native Cummins file CRCs.
- Discover installed RP1210 APIs/devices.
- Perform the recovered CLIP session authentication and calibration transfer flow.
- Provide a standalone CRC checker/setter.

## Build

### Requirements

- Windows
- Visual Studio C++ x86 build tools
- .NET 10 SDK
- A 32-bit RP1210 implementation for the adapter you intend to use

Run:

```bat
build.bat
```

The script locates/switches to the Visual C++ x86 toolchain, builds the native C core, builds the CRC utility, then publishes the WinForms application.

### Output layout

```text
build/
├── app/
│   └── CumminsCalTransfer.exe
├── tools/
│   └── crc_call.exe
├── native/
│   └── rp1210scan.dll
├── obj/
└── dotnet/
```

`rp1210scan.dll` is embedded into `CumminsCalTransfer.exe`; the copy under `build/native` is a build intermediate.

No Cummins `CRCUtility.dll` is required.

## CRC utility

Check a calibration file:

```bat
build\tools\crc_call.exe check mycal.ccal
```

Set the recovered file CRC fields:

```bat
build\tools\crc_call.exe set mycal.ccal
```

## Validation status

The raw calibration-loader stream generated by this implementation was compared request-for-request against the supplied Calterm capture:

- 2,287 requests generated
- 3,664,593 bytes generated
- 2,287 / 2,287 requests matched
- zero byte mismatches

Upload is gated by:

```text
CheckCalFileCRC
CheckHeaderFileCRC
CheckFileCRC
```

A bad file is rejected before the RP1210 adapter is opened.

The remaining live-test boundary is the CLIP-to-loader shutdown timing around the session-specific initiator close. See [docs/upload-validation.md](docs/upload-validation.md).

## Programming caution

ECM programming is not a read-only operation. Use stable vehicle power, a reliable RP1210 connection, and a calibration intended for the target module. Do not interrupt power or communications during an upload.
